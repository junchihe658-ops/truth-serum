# Truth Serum

[English](README.md) | **中文**

**一个不肯对你撒谎的回测审计器。**

> Binance Agent OS Mini Hackathon · Track A

每个交易 agent 的 demo 都会给你看一条漂亮的回测曲线。
这个项目做相反的事：**告诉你那条曲线里有多少是真的。**

```
你说：  「RSI 超过 60 做多、低于 40 做空，持 12 小时」

宣传的数字   SOLUSDT 年化 +62.2%（541 笔，胜率 53.4%）
账户的数字   平均折收益 −24.98%，复合 −90.4%
```

两个数字都是真的，来自同一份币安行情、同一段策略代码。
差额不是玄学，是两桩能算出来的事 —— 见「差额从哪来」。

## 一个把自己优化进偏差里的 agent

```bash
python examples/agent_demo.py     # 约 16 秒
```

`TunerAgent` 只被给了一个目标 —— 把每笔期望做到最高 —— 和一族 RSI 策略。
它自己搜完 147 组参数、挑出最好的一组，并把**每一次试验**都记进日志。

这个 agent 完全"诚实"：不偷看未来、不改数据、每一步可复现。
它唯一做的事情是：**在 147 组里挑了最好的那组。**

```
agent 的最好       −0.1017%/笔   （RSI(21) >70 / <38）
它那 147 组的中位   −0.1663%/笔

随机搜同样 147 次的最好成绩：中位 −0.0624%
                              ↑ 比 agent 精心挑出来的还好

⑤ 搜索选择偏差  →  ❌  p ≈ 1.000
```

**随机乱搜 147 次，比 agent 优化出来的参数还好。**

这不是作弊，这是**单一指标优化的必然结果** —— 对 agent 如此，对人也如此。
区别只在于：人调参时通常不记录自己试过多少组，于是这一整层偏差
直接消失在视野之外。

所以 `SearchLog` 是强制的。**只交出胜出者、不交出那 146 个失败的**，
本身就已经藏起了最常见的一种自欺。

## 装进你自己的 Claude

```bash
pip install -e .
claude mcp add truth-serum -- python -m truthserum.server
```

> **`pip install -e .` 这一步不能省。** 不装的话，`python -m truthserum.server`
> 只有在当前目录正好是本仓库时才找得到模块。而 MCP server 起不来**通常不报错**，
> 只会安静地不出现在工具列表里 —— 是最难查的那种失败。
>
> Windows 上如果 `python` 指向应用商店的占位程序，换成 Python 的绝对路径。
> 装完**要新开一个会话**：MCP 工具只在会话启动时加载。

暴露六个工具：

| 工具 | 干什么 |
|---|---|
| `list_gates` | 每道闸门抓什么 |
| `strategy_vocabulary` | 「用大白话描述策略」能用哪些说法 |
| `audit_plain_language` | **一句话 → 代码 → 全部闸门** |
| `audit_strategy` | 直接喂一段 `signal(bars)` 代码 |
| `fetch_market_data` | 把币安行情拉到本地缓存 |
| `save_mcp_reference` | 接收**官方 Binance MCP** 取到的 K 线作为核验参照 |

最后一个是**两个 MCP 协同**：你的 Claude 先调 `binance-mcp-server` 取 K 线，
把原始 JSON 交给 truth-serum 存成参照，之后每次审计自动逐根核验本地行情。

一个讲「不要盲信」的工具，自己的数据也得有人管。

## 自然语言这一层，宁可拒绝也不猜

**不调 LLM，也不执行任何外部代码。** 一套明确词汇表 + 一个只认这套词汇的
确定性解析器；代码由它生成，只可能用到词汇表里的算子。

它做的第一件事是**把解读回读给你确认**：

```
我理解成这样（请核对）：
  1. 24小时涨跌幅 > 3% 且 收盘价 > MA(20)   → 做多
  2. 收盘价 下穿 MA(20)                    → 观望

⚠ 这几处我替你做了选择，看看对不对：
  · 24小时 = 24 根 1h K 线
  · 「跌破 MA20」省略了主语，我按上一条的「收盘价」理解
  · 「下穿」我理解成【只在穿越那一根触发】
```

有歧义而未经确认，**它不会开跑**。认不出的说法一律拒绝，并指名是哪几个字：

```
> MACD 金叉就买入
没看懂「MACD 金叉」：开头这个量不在词汇表里
```

**一个把你的话猜成代码的翻译器，比不翻译更危险。**

## 闸门

从「最底层的前提」往上查。前提错了，后面的数字全部没有意义。

| 闸门 | 抓什么 |
|---|---|
| **⓪ 数据出处核验** | 你的 K 线本身是不是真的（拿官方 MCP 逐根比对） |
| **① 前瞻检测** | 未来数据改变了过去的信号 |
| **② 重叠计数** | 「平均每笔期望」被信号持续期灌水 |
| **③ 零假设本底** | 「筛了很多个，最好的那个看起来不错」—— 针对**单个**策略 |
| **④ 组合层模拟** | 账户里最后到底剩多少钱（唯一有资格下结论的一道） |
| **⑤ 搜索选择偏差** | 「我试了两百组，这组最好」—— 偏差藏在没交出来的那 199 组里 |

③ 和 ⑤ 不是一回事。③ 把**单个**策略的信号打乱；⑤ 问的是
「**搜索的胜出者**能不能赢过同样规模的随机搜索」。
一个搜了 147 组的 agent，能过 ③，过不了 ⑤。

⑤ 需要 `SearchLog`。没有就报**未检**，绝不报「没问题」——
**「没查」和「没问题」是两句话。**

### 三个真实案例（`python examples/make_report.py`）

在 4 个币、每币 9000 根 1h K 线上跑：

```
⓪①②③④⑤
✅❌✅✅✅⏭   偷看明天的收盘价       自称 SOLUSDT 年化 +3682.5%
✅✅✅❌❌⏭   全样本调参的三因子共振   自称 BTCUSDT 年化 +51.0%
✅✅❌❌❌⏭   诚实的 RSI 动量        自称 SOLUSDT 年化 +62.2%
```

**第一行最能说明问题。** 那个作弊策略，**除了前瞻那道，其余全部放行**：

- ③ 零假设本底：**显著优于随机（p ≈ 0.012）**
- ④ 组合层模拟：**账户层面盈利且显著，平均折收益 +71.75%，t = +3.95**

因为**作弊确实能赚钱**。只有 ① 抓到它。
这就是为什么前瞻必须排在最前面，也是为什么一道闸门不够。

**第三行最有说服力。** 一个完全合理、毫无作弊的教科书策略，依然过不了 ②③④。

## 差额从哪来：两桩能算出来的罪

`truthserum/naive.py` 里老老实实实现了一遍**大多数人自己写的那个回测器**。
它算出的数字是真的，只是算法是错的。

| | SOLUSDT，同一段行情、同一段代码 |
|---|---|
| 未扣成本 | 总收益 **+64.4%**，年化 **+62.2%** |
| 已扣成本 | 总收益 **−41.5%**，年化 **−40.6%** |

1. **漏掉手续费和滑点** —— 来回 0.1908% × 541 笔 ≈ 累计 **103% 的本金**，
   而未扣成本的毛利只有 64.4%。
2. **只报表现最好的那个标的** —— 同一策略 4 个币，BNB 即使不扣成本也是 **−26.5%**。

## 最核心的设计：每个检测器必须先证明自己没瞎

> **一个永远报「一切正常」的检测器，比没有检测器更危险。**

`Audit.report()` 在自检通过之前，**拒绝返回任何结论**：

```
⛔  ⑤ 搜索选择偏差
    检测器自检未通过 —— 不给出任何结论
    ├ 它本该抓到人为植入的 bug，但没抓到
    ├ 在检测器自己被修好之前，它说『干净』是没有意义的。
```

每道闸门的自检方式：

| 闸门 | 自检 |
|---|---|
| ⓪ | 人为篡改参照 0.01%，必须检出 |
| ① | 给策略套一层「偷看未来 1 根」的壳，必须抓到 |
| ② | 用恒定信号（重叠最大化），去重后笔数必须降到约 1/horizon |
| ③ | 植入「直接看未来」的策略，它必须显著跑赢自己的本底 |
| ④ | 抛硬币策略的每笔期望必须 ≈ −成本 |
| ⑤ | **双向**：纯噪声搜索必须被拦下，**且**真有优势的策略必须放行 |

⑤ 的自检刻意做成双向的。**只拦下噪声搜索什么也证明不了** ——
一个见谁都报警的闸门同样能通过那一半。

**这不是纸上谈兵。**

① 号闸门在写的时候连错三版，每一版都会在真实数据上报告「未发现前瞻」，
三次都是被自检拦下的。

⑤ 号闸门的第一版在 2026-09-05 同样被自检拦下。为了让本底跑得快，
它先采样一个随机成绩池，再从池子里有放回地重抽 best-of-N ——
**但重抽的最大值永远超不过池子的最大值**，真实胜出者一旦更高，
p 就自动为 0。自检报告「纯噪声搜索没有被拦下」，
于是整道闸门返回**「不可判定」**，而不是一个自信的错误答案。

## 这个工具做不到什么

**它是证伪器，不是认证器。**
挂了闸门是**强**信号：抓到了具体的、可复现的失败机制。
全部通过是**弱**信号：只说明这几种已知死法没被检出，**不等于**能赚钱。

具体的弱点，写出来不藏着：

- **自检是必要不充分的。** 它只证明这道闸门抓得住**那一个**人为植入的 bug。
  ① 号证明了它抓得住「偷看未来 1 根」，**不代表**它抓得住时区错位、跨周期对齐。
- **⓪ 是抽检。** 当前参照覆盖 91 根 / 全量 36000 根 ≈ 0.25%。
  抽样一致不等于全量一致。覆盖不全时判「未检」，绝不打勾。
- **④ 的成本自检容差很松。** 它接受抛硬币期望落在 `(−3×成本, +0.5×成本)`。
  成本模型错 3 倍照样能过。
- **③ 的自检抽样次数少于正式跑**（5 次 vs 80 次）。
- **⑤ 的本底用的是独立抽样**，而真实搜索的参数组高度相关
  （RSI 阈值差 5 的两组信号几乎一样）。有效独立试验数小于名义次数，
  所以 ⑤ 偏向于报警。
- **没有资金费。** `Costs` 只含手续费和滑点。永续持 12 小时必然跨 1~2 次结算。
- **成本模型是 OKX 实测的，数据是币安的。** 手续费接近，滑点不可移植。
- **缓存永不过期**，而且命中缓存时不吭声。
- **只有一年数据、单一市场状态**，跨不了牛熊。

还有最该说的一条：**就这个示例策略而言，决定性的那个数字是小学算术。**
去重叠后毛期望 +0.0102%，来回成本 0.1908% —— **边缘只有成本的 1/19**，
拿计算器就能验。五道闸门的价值不在于得出这个结论，
而在于**解释为什么原始数字看着不错**（重叠计数把同一个机会数了 7.4 遍）。

## 为什么会有这个东西

2026 年 9 月 1 日，作者的一套自动交易系统在走向前验证里显示：
**44 折全部盈利，SOL 复合收益 +2286%，平均胜率 68%。**

同一天下午查出来：K 线特征和衍生品数据用了两套差 8 小时的时间基准，
把代码里一条防前瞻的缓冲整个抵消掉了 —— **回测能读到未来 4 小时的数据。**

| | 泄露版 | 修复后 |
|---|---|---|
| 44 折平均 AUC | **0.6765** | **0.5017** |
| 盈利折 | 44/44 | 5/44 |
| SOL 复合收益 | +2286% | −20.2% |

**AUC 0.5017 = 与抛硬币无法区分。** 两个月的工作全部作废。

更糟的是这已经是第二次 —— 半个月前刚抓到过一次 297 小时的前瞻。
两次都是人手工挖出来的，挖到之后各补一个专项测试，然后等下一次。

**Truth Serum 就是那个「不用等下一次」的东西。**

## 数据出处

行情走**币安公开 REST 接口**，落到本地 parquet 缓存后再做审计。

**官方 Binance MCP Server 的角色是核验参照，不是取数通道**：⓪ 号闸门拿它
返回的 K 线逐根比对本地缓存，抓镜像源偏差、现货/合约混用、模拟盘假影线。
每份报告都印出数据出处（来源、区间、抓取时间），结论可追溯。
