# Truth Serum

**一个不肯对你撒谎的回测审计器。**

> Built for the Binance Agent OS Mini Hackathon (Track A)

每个交易 agent 的 demo 都会给你看一条漂亮的回测曲线。
这个项目做的是相反的事：**告诉你那条曲线里有多少是真的。**

---

## 为什么会有这个东西

2026 年 9 月 1 日，作者的一套自动交易系统在走向前验证里显示：
**44 折全部盈利，SOL 复合收益 +2286%，平均胜率 68%。**

同一天下午查出来：K 线特征和衍生品数据用了两套差 8 小时的时间基准，
把代码里一条防前瞻的缓冲整个抵消掉了 —— **回测能读到未来 4 小时的数据。**

修好之后：

| | 泄露版 | 修复后 |
|---|---|---|
| 44 折平均 AUC | **0.6765** | **0.5017** |
| 盈利折 | 44/44 | 5/44 |
| SOL 复合收益 | +2286% | −20.2% |

**AUC 0.5017 = 与抛硬币无法区分。** 两个月的调参、集成、成本校准，全部作废。

更糟的是，这已经是第二次了 —— 半个月前刚抓到过一次 297 小时的前瞻。
两次都是人手工挖出来的，挖到之后各补一个专项测试，然后等下一次。

**Truth Serum 就是那个"不用等下一次"的东西。**

## 四道闸门

```python
from truthserum import check

report = check(bars, my_strategy, claimed="回测年化 +212%")
print(report.render())
```

| 闸门 | 抓什么 | 真实教训 |
|---|---|---|
| **① 前瞻检测** | 未来数据改变了过去的信号 | 时区错位让 AUC 从 0.50 虚高到 0.68 |
| **② 重叠计数** | 单笔期望被"信号持续多久"加权 | 把 −0.0124% 抬成 +0.0945%，足以变号 |
| **③ 零假设本底** | "筛了 20 个，最好的那个不错" | 随机信号里最好的能做出 +14%，真实的才 +9.47% |
| **④ 组合层模拟** | 用单笔期望冒充账户收益 | 单笔 +0.0945% 的策略，账户层面年化 **−42%** |

---

## 最核心的设计：每个检测器都必须先证明自己没瞎

> **一个永远报「一切正常」的检测器，比没有检测器更危险。**

所以 `Audit.report()` 在自检通过之前，**拒绝返回任何结论**：

```
⛔  ① 前瞻检测
    检测器自检未通过 —— 不给出任何结论
    ├ 它本该抓到人为植入的 bug，但没抓到
    ├ 在检测器自己被修好之前，它说『干净』是没有意义的。
```

每道闸门的自检方式：

- **① 前瞻** —— 给策略套一层「偷看未来 1 根」的外壳，必须抓到
- **② 重叠** —— 用恒定信号（重叠最大化），去重后笔数必须降到约 1/horizon
- **③ 本底** —— 植入一个「直接看未来」的策略，它必须显著跑赢自己的本底
- **④ 组合** —— 抛硬币策略的每笔期望必须 ≈ −成本（可精确验证的不变量）

**这不是纸上谈兵：写这个项目时，① 号闸门的第一版就被自检当场判定失效。**
原因是我拿「截断版」和「全量版」比，两边都留了未来数据，
偷看 1 根的差异被 padding 抹平了。改成两个不同长度的截断互比才对。

算上生产系统上的三次，这类错误**已经被自检拦下四次**。

## 数据

行情走 **Binance MCP Server**（`https://agent.binance.com/mcp/agentic`），
落到本地 parquet 缓存后再做审计 —— 演示不会因为交易所抖动而翻车。
每份报告都会印出数据出处（来源、区间、抓取时间），结论可追溯。

未授权 MCP 时自动退回公开行情接口，功能不受影响。
